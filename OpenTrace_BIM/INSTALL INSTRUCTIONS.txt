OPEN TRACE BIM — INSTALL INSTRUCTIONS
=====================================

=======================================================================
IMPORTANT — CHECK THE FOLDER AFTER EXTRACTING
DO NOT LEAVE A DOUBLE OpenTrace_BIM FOLDER.

CORRECT:
...\ingetrazo\plugins\OpenTrace_BIM\__init__.py

WRONG:
...\ingetrazo\plugins\OpenTrace_BIM\OpenTrace_BIM\__init__.py
=======================================================================

The three images in this folder show the correct installation:
01_OPEN_PLUGINS_FOLDER.png
02_PLUGINS_FOLDER.png
03_OPENTRACE_BIM_CONTENTS.png


ENGLISH
-------
OPTION A — ONE-CLICK INSTALLER (Windows)
1. Extract the downloaded ZIP to any normal folder, such as Downloads.
2. Double-click INSTALL_OPENTRACE_BIM.bat next to the OpenTrace_BIM folder.
3. The installer copies OpenTrace_BIM to the correct IngeTrazo plugins folder.
4. Restart IngeTrazo.

OPTION B — MANUAL INSTALLATION
1. Open IngeTrazo.
2. Go to Extensions > Open plugins folder. See image 01.
3. Copy or drag the OpenTrace_BIM folder directly into the plugins folder. See image 02.
4. Open OpenTrace_BIM and verify that __init__.py is directly inside it. See image 03.
5. Restart IngeTrazo.

IMPORTANT: Do not create OpenTrace_BIM\OpenTrace_BIM. If you see two folders
with the same name nested inside each other, move the INNER folder one level up.

To update: replace the existing OpenTrace_BIM folder with the new one, or run
the installer again. The installer keeps one backup named OpenTrace_BIM_backup.


FRANÇAIS
--------
OPTION A — INSTALLATEUR EN UN CLIC (Windows)
1. Extrayez le ZIP téléchargé dans un dossier normal, par exemple Téléchargements.
2. Double-cliquez sur INSTALL_OPENTRACE_BIM.bat à côté du dossier OpenTrace_BIM.
3. L'installateur copie OpenTrace_BIM dans le dossier de plugins correct d'IngeTrazo.
4. Redémarrez IngeTrazo.

OPTION B — INSTALLATION MANUELLE
1. Ouvrez IngeTrazo.
2. Allez dans Extensions > Open plugins folder. Voir l'image 01.
3. Copiez ou faites glisser le dossier OpenTrace_BIM directement dans le dossier plugins. Voir l'image 02.
4. Ouvrez OpenTrace_BIM et vérifiez que __init__.py se trouve directement à l'intérieur. Voir l'image 03.
5. Redémarrez IngeTrazo.

IMPORTANT : ne créez pas OpenTrace_BIM\OpenTrace_BIM. Si deux dossiers du même
nom sont imbriqués, déplacez le dossier INTÉRIEUR d'un niveau vers le haut.

Pour mettre à jour : remplacez le dossier OpenTrace_BIM existant par le nouveau,
ou relancez l'installateur. L'installateur conserve une sauvegarde appelée
OpenTrace_BIM_backup.

DEUTSCH
-------
OPTION A — EIN-KLICK-INSTALLATION (Windows)
1. Entpacken Sie die heruntergeladene ZIP-Datei in einen normalen Ordner, z. B. Downloads.
2. Doppelklicken Sie auf INSTALL_OPENTRACE_BIM.bat neben dem Ordner OpenTrace_BIM.
3. Das Installationsprogramm kopiert OpenTrace_BIM in den richtigen IngeTrazo-Plugin-Ordner.
4. Starten Sie IngeTrazo neu.

OPTION B — MANUELLE INSTALLATION
1. Öffnen Sie IngeTrazo.
2. Gehen Sie zu Extensions > Open plugins folder. Siehe Bild 01.
3. Kopieren oder ziehen Sie den Ordner OpenTrace_BIM direkt in den Plugin-Ordner. Siehe Bild 02.
4. Öffnen Sie OpenTrace_BIM und prüfen Sie, dass __init__.py direkt darin liegt. Siehe Bild 03.
5. Starten Sie IngeTrazo neu.

WICHTIG: Erstellen Sie nicht OpenTrace_BIM\OpenTrace_BIM. Wenn zwei gleichnamige
Ordner ineinander liegen, verschieben Sie den INNEREN Ordner eine Ebene nach oben.

Zum Aktualisieren: Ersetzen Sie den vorhandenen OpenTrace_BIM-Ordner durch den
neuen oder führen Sie das Installationsprogramm erneut aus. Das Installationsprogramm
behält eine Sicherung mit dem Namen OpenTrace_BIM_backup.
